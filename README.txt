Pages.dev deployment package

- index.html is the main landing page with all 100 article cards and title search.
- articles/ contains one standalone HTML page for each supplied title.
- The URL https://getchatsupport.net/ is only used as the destination of inner "Contact Support" buttons.
- The site is an independent informational resource and does not claim to be the official Bitdefender website.

Deploy: upload the contents of this ZIP to your Pages.dev project or compatible static hosting. Keep the articles folder beside index.html.
